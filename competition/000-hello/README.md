# 000-hello

The classic warm-up.

## Task

Greet every name on the input. Read it line by line — each line holds one
name — and for each one print `hello, ` followed by that name on its own line,
keeping the original order.

## Examples

A single name in, the matching greeting out:

```
Input:
world

Output:
hello, world
```

Several names — greet each, in order:

```
Input:
alex
cono

Output:
hello, alex
hello, cono
```

Only the basic case is shown here; further hidden tests are applied when the
competition is finalized, so solve the general task rather than just these
examples.
